# Skills and library
> **Job:** Reusable knowledge the agent loads on demand.

## Skills

Skills are named markdown notes with a description (e.g. `email-triage`: how you like mail sorted). Sessions see only the index — name plus one line each. The agent reads a skill's full body when it looks relevant.

Manage them on the Skills page: create, edit, delete, search. Bodies live as markdown files under the app data dir and sync both ways with the database.

## Library

The library is a file shelf: add documents, list, search, open, delete. The agent reads library files to answer from your own material. Large texts page in on demand instead of flooding context.
